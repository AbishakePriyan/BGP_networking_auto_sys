# Training audit

## Existing synthetic experiment

`train.py` generated 2,400 simulated feature rows with seed 42, evenly split between the two synthetic classes. It trained a scikit-learn RandomForestClassifier with 150 trees, max depth 8 and balanced class weights. A stratified random 75/25 split produced 1,800 training rows and 600 test rows. The stored confusion matrix was `[[300, 0], [0, 300]]`. These scores are **not real-world detection performance**: the generator sets `origin_mismatch` equal to the label, so the target is present in the inputs. No conclusion about generalization or model superiority is warranted. The API uses a lab authorization rule, not this model.

The historical file `data/youtube_2008.jsonl` has 38 RIPE RRC00 observations, including 26 collector observations matching one documented incident and 12 unknown observations. Those 26 observations are not independent incidents. There are no reviewed benign labels. The available historical data has not been used to train a model. The preceding RIB and selected UPDATE files have an incomplete interval. See DATASET_CARD.md for source and caveats.

The training audit endpoint `/api/model/audit` reports counts and blockers. A proposed group/time splitter rejects insufficient groups, overlapping windows and partitions missing a class. A guarded historical training command now exists; no eligible real-data training or real-data evaluation has been performed. An independently reviewed, multi-incident corpus with defensible benign examples and a complete causal feature pipeline are still needed before claiming deployable model accuracy.

To reproduce the existing *synthetic-only* experiment, run `.venv/bin/python train.py`. **This overwrites the local synthetic artifacts** in `artifacts/` and `data/synthetic_training.csv`; preserve any artifacts you wish to keep first. The experiment was rerun in this session without overwriting the prior artifact: `.venv/bin/python experiments/synthetic-demo/train.py`. The separate run produced the same synthetic confusion matrix. Its generated dataset, model, metrics and checksums are under `experiments/synthetic-demo/`; see `run_manifest.json`.

## Historical feature export

`python -m pipeline.build_features --input data/youtube_2008.jsonl --output data/features/youtube_2008.jsonl` created a 38-row JSONL feature export and SHA-256 manifest. Output refuses to overwrite an existing file. `historical-update-v1` only uses supplied observations strictly before the timestamp; equal timestamps are processed as a batch. RIB rows seed prior state but do not count as UPDATE announcements. Unknown AS paths and ambiguous origins remain null. Counts describe collector observations rather than independent incidents. `history_complete` is false because the sample has a gap; a zero count is only a count within supplied history, not proof that no prior event occurred. The historical contract is explicitly incompatible with FRR RIB polling and is not used for a trained or active model. Incident IDs, provider labels and confidence are retained as metadata and are not features.

## Guarded future real-data training

`python -m pipeline.real_training --input path/to/reviewed_features.jsonl --output-dir artifacts/real-experiment` compares a prior-origin rule and Random Forest. It demands the exact historical feature schema, explicit source attribution and time-window groups, attested complete preceding histories, non-overlapping group windows, and both reviewed classes in each time-ordered train/validation/test partition. Unknown labels are excluded. Preprocessing fits training data only and includes an explicit missingness indicator for every feature. The rule baseline abstains when origin history is missing and reports its coverage. The model threshold is chosen on validation F1, with the test set held out; Random Forest scores are uncalibrated. The report includes observation-level false positives and per-group results. The input and output directory must be chosen by the operator; the output directory must not already exist.

The software validates structure and splits but **does not independently prove** that a label is correct or that the history-completeness assertion is true. The current RIPE feature file explicitly has `history_complete: false`, one incident and no reviewed negatives; running the command on it fails before training or creating an output directory. This historical UPDATE model cannot be used with the lab's RIB polling. No validated real-data model exists yet.
